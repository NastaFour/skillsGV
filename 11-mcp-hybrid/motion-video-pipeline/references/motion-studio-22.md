# Open-Source Motion Studio — 22 Verified Repositories (Tier A–D)

Curated 22-repository reference stack indexed for [`SKILL.md`](../SKILL.md) and [`web-animation-sources`](../../../05-frontend/web-animation-sources/SKILL.md). Choose the narrowest tier that fits the deliverable instead of over-bundling video runtimes into live UIs.

## Tier A — Code-to-Video & Timeline Engines (6 Repos)

1. **`remotion-dev/remotion`** (`https://github.com/remotion-dev/remotion`) — Programmatic React video compositions rendered frame-by-frame to MP4/WebM.
2. **`motion-canvas/motion-canvas`** (`https://github.com/motion-canvas/motion-canvas`) — TypeScript generator-based 2D procedural animation studio with live timeline scrubbing.
3. **`3b1b/manim`** (`https://github.com/3b1b/manim`) — Original Python mathematical & technical diagram explanatory engine (`ManimGL`).
4. **`ManimCommunity/manim`** (`https://github.com/ManimCommunity/manim`) — Community-maintained Python deterministic explainer engine for formulas, graphs, and vector reveals.
5. **`theatre-js/theatre`** (`https://github.com/theatre-js/theatre`) — High-precision keyframe curve editor & animation state sheet for React, Three.js, and DOM pipelines.
6. **`tweenjs/tween.js`** (`https://github.com/tweenjs/tween.js`) — Lightweight deterministic numeric interpolation engine for scripted frame steppers.

## Tier B — Web UI, Scroll & Vector Choreography (6 Repos)

7. **`motiondivision/motion`** (`https://github.com/motiondivision/motion`) — Hybrid spring/scroll/layout engine for React & vanilla DOM (`WAAPI` + JS spring loop).
8. **`greensock/GSAP`** (`https://github.com/greensock/GSAP`) — Precision ScrollTrigger, SplitText, MorphSVG, and sequenced UI timelines.
9. **`juliangarnier/anime`** (`https://github.com/juliangarnier/anime`) — Compact timeline & SVG stroke-dashoffset choreography engine (`Anime.js`).
10. **`airbnb/lottie-web`** (`https://github.com/airbnb/lottie-web`) — JSON vector playback engine for After Effects / Bodymovin motion graphics.
11. **`Rive-app/rive-wasm`** (`https://github.com/Rive-app/rive-wasm`) — State-machine interactive vector & bone runtime via WebAssembly.
12. **`Popmotion/popmotion`** (`https://github.com/Popmotion/popmotion`) — Composable functional physics (`spring`, `inertia`, `keyframes`) for custom animation primitives.

## Tier C — 3D WebGL, Shaders & Spatial Scene Pipelines (5 Repos)

13. **`mrdoob/three.js`** (`https://github.com/mrdoob/three.js`) — Core WebGL/WebGPU scene graph, PBR materials, lights, and custom shader passes.
14. **`pmndrs/react-three-fiber`** (`https://github.com/pmndrs/react-three-fiber`) — Declarative React reconciler over Three.js with deterministic frame-loop scheduling.
15. **`pmndrs/drei`** (`https://github.com/pmndrs/drei`) — Battle-tested camera rigs, shaders, environment maps, and HTML portals for R3F.
16. **`pmndrs/postprocessing`** (`https://github.com/pmndrs/postprocessing`) — Merged-pass bloom, chromatic aberration, DOF, and tone-mapping compositor.
17. **`CurtainsJS/curtainsjs`** (`https://github.com/CurtainsJS/curtainsjs`) — DOM-synchronized WebGL shader quads mapping HTML images/videos onto interactive planes.

## Tier D — FFmpeg Encoding, Headless Capture & Audio-Sync Tooling (5 Repos)

18. **`FFmpeg/FFmpeg`** (`https://github.com/FFmpeg/FFmpeg`) — Canonical CLI muxer, filtergraph compositor, LUT color pipeline, and hardware-accelerated encoder.
19. **`fluent-ffmpeg/node-fluent-ffmpeg`** (`https://github.com/fluent-ffmpeg/node-fluent-ffmpeg`) — Node.js programmable pipeline builder wrapping complex `ffmpeg` filtergraphs.
20. **`puppeteer/puppeteer`** (`https://github.com/puppeteer/puppeteer`) — Headless Chromium deterministic canvas/DOM screenshot capture at locked timestamps.
21. **`microsoft/playwright`** (`https://github.com/microsoft/playwright`) — Multi-browser deterministic frame capture, WebGL video recording, and visual regression verification.
22. **`bbc/audiowaveform`** (`https://github.com/bbc/audiowaveform`) — Waveform envelope extraction (`JSON`/binary peaks) for beat-locked motion cue synchronization.
